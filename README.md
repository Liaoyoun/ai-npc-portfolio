# AI NPC 對話系統

一個使用 Python 與 Streamlit 製作的互動式 AI NPC 作品集專案。

玩家可以在瀏覽器中與 NPC「艾琳」對話。艾琳具備角色設定、短期記憶、情緒狀態，以及依照玩家訊息做出行為決策的能力。

## 專案功能

- 瀏覽器即時對話介面
- NPC 角色背景與個性設定
- 保存目前遊玩期間的短期對話記憶
- 根據玩家訊息改變情緒
- 根據關鍵字選擇對應行為
- 一鍵清除對話並重置 NPC 狀態

## NPC 設定

- 名字：艾琳
- 身分：王城圖書館守護者
- 個性：冷靜、謹慎、富有好奇心
- 任務：保護圖書館並協助可信任的訪客

## 決策流程

玩家輸入訊息後，系統會：

1. 保存玩家訊息
2. 分析訊息中的關鍵字
3. 更新 NPC 情緒
4. 選擇 NPC 行為
5. 產生符合狀態的回覆
6. 保存 NPC 回覆至短期記憶

## 使用技術

- Python 3.13
- Streamlit 1.60
- Session State
- 規則式行為決策
